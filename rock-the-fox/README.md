# Rock the Fox product page

Expanded September 2026 to share Teachin’ Time’s product-page structure, typography, navigation, and screenshot presentation, with a black/red concert identity.

Serve the repository root. This page uses its own `fox.css` and `fox.js`; no shared CSS was changed. Existing support, privacy, and App Store destinations are retained. The portfolio homepage uses the new app card and gallery screen.

Assets derive from the supplied iPhone captures. UI content and photographs are preserved. The six marketing portraits add an atmospheric concert background and typography around the original UI. Program cards show cropped portions of the original program pages; the complete views are available in the screenshot gallery. Image previews use a native dialog with keyboard dismissal; the mobile navigation is usable without JavaScript. Reduced motion is respected.

Publishing follows the existing GitHub Pages main-branch workflow.
