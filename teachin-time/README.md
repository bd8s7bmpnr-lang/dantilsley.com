# Teachin’ Time website

Six static pages share `teachin.css` and `teachin.js`: overview, features, calendars, moments, support and privacy. No framework, external fonts, analytics or build step.

## Artwork

The JPEG assets are optimized exports of the Teachin’ Time 3.0 App Store campaign supplied and approved in the project. These are marketing compositions, not pixel-identical UI captures. The morning weather is illustrative. iPad matching-game artwork reflects the corrected layout. Original full-resolution PNGs remain in the project output folder.

## Release status

The site presents version 3.0 as coming soon. After its App Store release is confirmed, update the homepage release pill and the release notes beneath the App Store links. School-calendar coverage is qualified; the site does not promise every BC school or future schedule changes.
