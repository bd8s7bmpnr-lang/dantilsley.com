Data Sources & Acknowledgements

Where Heard’s live APRS information, optional callsign records, map content, and external lookups come from, and what is stored locally.

Last reviewed August 1, 2026 · Data Sources URL: /heard/data-sources/
Heard combines live APRS traffic with optional reference data. A directory registration location is not a station’s live APRS position, and neither should be treated as proof of a person’s current location.
Live network

APRS-IS

Heard connects to APRS-IS to receive public APRS packets for the listening area selected by the user. APRS-IS is a community-operated internet system that interconnects APRS gateways and servers.

Heard uses APRS-IS packets to populate the map, station list, station detail views, movement trails, message views, and connection diagnostics. Packet availability, accuracy, routing, and retention are controlled by transmitting stations and the broader APRS network, not by Dan Tilsley.

United States directory

FCC Universal Licensing System

Optional U.S. amateur callsign information is derived from public FCC Universal Licensing System data. Heard uses this data to show locally searchable callsign and licence context when the user installs the U.S. directory.

After installation, Heard stores the local fields needed by the app, such as callsign, name, entity type, city, state, operator class or qualification when available, source date, record count, and storage status.

Canadian directory

ISED Canadian amateur radio data

Optional Canadian amateur callsign information is derived from public data provided by Innovation, Science and Economic Development Canada. Heard uses this data to enrich station details and local callsign searches when the Canadian directory is installed.

The source provider controls availability of the download. Heard treats the Canadian directory as optional and allows users to retry updates or remove the local copy when needed.

External lookup

QRZ

Heard can open callsign pages on QRZ in an in-app browser when a user chooses the QRZ action. QRZ is not bundled as a local directory in Heard, and Heard does not represent QRZ or guarantee its content, availability, account behavior, or privacy practices.

Map content

Apple Maps

Maps, place labels, imagery, and related cartographic content are provided through Apple MapKit. Heard uses map content to display APRS stations, listening areas, and nearby geographic context.

Attribution

Independent product

Heard is independently developed by Dan Tilsley and is not affiliated with or endorsed by APRS-IS, the FCC, ISED, QRZ, Apple, or individual amateur-radio operators whose public station data appears in the app.

What is stored locally

Live APRS activity, app settings, selected listening areas, and optional directory records may be stored on the device so Heard can display recent activity, search installed directories, and preserve user preferences. Optional FCC and ISED directories can be removed from Settings.

Accuracy and responsible use

Public radio and licensing data can be delayed, incomplete, inaccurate, stale, or intentionally approximate. Station symbols and descriptions are supplied through APRS and may not always describe a station perfectly. Heard should be used as an exploratory amateur-radio tool, not for emergency response, surveillance, navigation, or decisions where precise identity or location is required.

Corrections

Dan Tilsley cannot directly alter government licensing records, QRZ pages, map content, or APRS packets transmitted by other stations. Questions about a source record should be directed to the organization that maintains that source. Product display issues can be reported through the Heard support page.
